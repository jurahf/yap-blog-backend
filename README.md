# yap-blog-backend

Учебный проект для Яндекс.практикум, курс Middle Java.  
Проект представляет собой бекенд для блога.

## Как устроен проект
  Проект разбит на слои
  1. Обработка запросов
	  - controller - возвращает DTOs
	  - принимает RequestsDTO, возвращает DTO
 	  - принимает запрос и обращается в сервисный слой
  2. Сервисный слой
	  - service 
	  - принимает и возвращает DTO, в том числе RequestDTO
	  - содержит в себе логику
	  - преобразует DTO в DAO-model и обратно
	  - обращается за данными в repository
  3. DAO
	  - repositories работает только с DAO-model
	  - выполняет запросы в БД
  
## Сборка
Для сборки выполнить команду

`gradle build`

Архив будет создан в каталоге `build/libs/`
